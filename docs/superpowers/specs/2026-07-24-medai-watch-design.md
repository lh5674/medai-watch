# MedAI Watch 设计说明

## 目标与边界

MedAI Watch 是黑客松研究原型，用于监测一个既有图像分类模型在受控图像扰动下的预测与 Grad-CAM 解释是否稳定，并据此提示是否需要人工复核。系统不诊断患者、不推荐治疗、不声称具有临床有效性。

当前工作区没有可复用的医学影像模型、权重、标签、预处理、解释代码或应用代码。因此项目采用双模式集成：

1. **真实模型模式**：加载用户明确配置的 torchvision 架构和匹配的 `state_dict` 权重、类别标签、输入尺寸、归一化参数及 Grad-CAM 层。
2. **模拟演示模式**：使用固定权重、无随机初始化的微型 PyTorch 卷积网络与非临床标签“演示类别A/演示类别B”。所有界面、报告和导出均明确标注“模拟演示案例，不代表真实模型或临床结果。”，不得将该输出描述为真实医学模型结果。

## 架构

系统采用确定性的单进程工作流，不依赖外部 LLM：

```text
PIL 图像
  -> ImageQualityService
  -> PredictorService
  -> GradCAMService
  -> PerturbationService (blur/noise/brightness)
  -> PredictorService + GradCAMService
  -> SimilarityService
  -> RiskEngine
  -> ReportGenerator
  -> SQLiteRepository
  -> Streamlit 分析页与仪表盘
```

`MedicalAIWatchAgent` 只负责编排；每个服务保持单一职责并通过普通 Python 字典或 NumPy 数组通信。可序列化结果与仅供显示的数组分离，数据库只存标量、文本及生成资产路径。

## 模型集成

`PredictorService` 在构造时只加载一次模型，选择 CUDA（可用时）或 CPU，调用 `eval()`，并在 `torch.inference_mode()` 中推理。真实模型配置支持 `resnet18`、`resnet34` 与 `densenet121`，替换最终分类层后严格加载 `state_dict`。加载失败时返回包含配置路径、期望类别数和原始异常的明确错误，不自动退回模拟结果。

输入统一转换为 RGB，验证 PIL 图像与尺寸，按配置 resize、转 tensor、normalize。输出包含类别索引、类别名、置信度、完整概率字典、推理耗时、模型版本、设备和 `is_demo`。

模拟模型使用手工固定卷积核与分类权重，启动过程不读取随机状态。它仅用于证明端到端工作流、Grad-CAM、数据库和界面可运行。

## 图像质量与扰动

图像质量服务检查文件可解码性、最小/最大尺寸、有限数值、极端像素占比、Laplacian 方差、平均亮度和标准差对比度。各子分数限制为 `[0, 1]`，总分为配置权重加权值并转换为 `[0, 100]`。问题描述只谈技术质量，不给出医学含义。

扰动函数保留尺寸和输入模式：

- 高斯模糊：奇数核且大于等于 3。
- 高斯噪声：`numpy.random.default_rng(seed)`，sigma 限制在 `[0, 1]`。
- 亮度调整：factor 限制在 `(0, 3]`。

计算使用浮点 `[0, 1]`，输出前裁剪，避免溢出和下溢。

## Grad-CAM 与相似度

Grad-CAM 采用本地实现，通过前向钩子捕获指定卷积层激活，通过完整反向钩子捕获梯度。目标层可由点路径配置；未配置时选择模型最后一个 `nn.Conv2d`。不存在卷积层时抛出明确错误。热力图使用 ReLU、双线性上采样和安全 min-max 归一化，并生成 RGB 叠加图。

所有扰动图像均以原始预测类别为 Grad-CAM 目标。相似度同时计算：

- 归一化热图展平后的余弦相似度，限制为 `[0, 1]`。
- `skimage.metrics.structural_similarity`，映射并限制为 `[0, 1]`。

空热图报错；两个相同常量热图返回 1，一个常量一个非常量返回 0，避免 NaN。

## 风险评分

风险引擎完全由配置驱动：

```text
risk =
    0.25 × (1 - 原始置信度)
  + 0.35 × 类别变化测试数 / 测试总数
  + 0.25 × (1 - 平均解释相似度)
  + 0.15 × (1 - 质量分 / 100)
```

单次扰动的解释相似度取余弦与 SSIM 的平均值。最终分数限制在 `[0, 100]`。小于 30 为“通过”，小于 60 为“谨慎使用”，否则为“建议人工复核”。界面和报告同时展示每个组成项及固定免责声明。

## 持久化与资产

SQLite 自动创建 `analyses` 和 `perturbation_results` 表，启用外键并只使用参数化 SQL。每次分析保存原图、原始 Grad-CAM、扰动图及其 Grad-CAM 到以 UUID 命名的资产目录，再将相对或绝对路径写入数据库。写入分析主记录与扰动记录处于同一事务。

## 界面

`app.py` 是单病例分析入口，使用宽布局、中文文案、醒目研究免责声明、模型状态、上传器/模拟样例选择、扰动参数、进度、原图与 Grad-CAM、概率图、扰动标签页、风险组成图、报告和 JSON/CSV 下载。

`pages/2_监控仪表盘.py` 提供总数、高风险数量/比例、平均风险、决策分布、扰动失败分布、日期/类别/决策筛选、近期记录和展开详情。颜色与文字/图标同时表达决策。

三个模拟样例由 NumPy/Pillow 确定性生成，分别用于界面演示稳定、置信度变化和类别变化场景；它们不预存伪造“真实模型”结果，实际展示值必须来自当前模拟适配器的执行。中风险样例使用噪声强度 `0.25`、随机种子 `42` 的单项压力测试。

## 错误处理

- 无法解码图像：在推理前返回中文可操作错误。
- 权重缺失：真实模式启动失败并提示接入位置，不静默切换。
- 权重不兼容：显示架构、类别数和 `state_dict` 加载异常。
- Grad-CAM 层无效：列出配置路径和自动发现结果。
- 数据库或资产写入失败：事务回滚，界面保留分析结果并报告未保存。
- CUDA 推理失败不自动改变结果语义；初始化阶段可按配置选择 CPU。

## 验证标准

1. 单元测试覆盖扰动、质量、相似度、风险边界、数据库和模型错误。
2. 模拟适配器完成一次包含三种扰动、Grad-CAM、风险、报告和数据库写入的端到端分析。
3. Streamlit 以 headless 模式启动并返回健康状态。
4. 仪表盘查询在新建和已有数据库上均成功。
5. 所有可见评分与模拟输出包含正确免责声明。

## 已知限制

本设计不验证任何疾病标签、数据集外推、校准、公平性或临床有效性。Grad-CAM 相似度只反映数值稳定性，不证明关注区域医学正确。固定扰动强度和原型权重尚未经过临床验证。真实模型接入必须由模型所有者提供准确架构、权重、标签与预处理元数据。
